# omnisense/omnicrawl

**Reserved, not released yet.**

Fetch and extract web pages through crawling services, responsibly by default: robots.txt honoured, a usage policy per target site, an identified User-Agent, provenance kept on every record, under any PHP host. One contract by capability, one package per provider, as every family of the
[Omni ecosystem](https://glitchr-omnisense.github.io/omnisense/). Its first providers: Apify, Firecrawl, ScrapingBee, Zyte API.

Responsible by default: a target site that does not allow it is refused by the family itself,
not left to each caller.

The name is kept so that the family is built here, once. To write or maintain one of its
providers, see the site's [contribute page](https://glitchr-omnisense.github.io/omnisense/contribute) and open a "Provider" issue there.
